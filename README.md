Wahadat Laundry Services - Website README
🌐 Website Overview
This is a modern, fully responsive single-page website for Wahadat Laundry Services located in Sharjah, UAE. It is built using HTML5, CSS3, and Vanilla JavaScript and includes animations, sliders, and an interactive contact form.

📄 File Structure
index.html: The main (and only) file containing the website's structure, styling, and functionality.

README.md (this file): Instructions on how to use and edit the website.

🚀 How to Run the Website
Save the index.html file on your computer.

Double-click index.html to open it in any web browser (Chrome, Edge, Safari, etc.).

To upload it to the internet, simply upload this index.html to your web hosting (like cPanel, Netlify, Vercel, or GitHub Pages).

🛠️ How to Edit the Website (For Boss & Developers)
1. Change Phone Number
Search for this number: +971 55 710 0191 (replace it with your new number wherever it appears).

2. Change Social Media Links
Search for the following placeholder links and replace them with your actual profile links:

https://facebook.com

https://instagram.com

https://youtube.com

(The WhatsApp button is already linked to https://wa.me/971557100191).

3. Update the Contact Form (Important!)
The contact form currently uses mailto:your-email@example.com.

Search for: action="mailto:your-email@example.com"

Replace with: action="mailto:your-real-business-email@email.com"

(Note: To receive messages properly on a live server, you may want to use a service like Formspree or Getform instead of mailto).

4. Change the Hero / Gallery Images
Images are loaded via URLs (Cloud/Unsplash).

Hero Slider: Search for background-image: url('https://images.unsplash.com...') to change the sliding background images.

Gallery & Moving Strip: Search for <img src="..."> in the "Gallery" and "Frame Strip" sections and replace the URLs with your own cloud-hosted images.

5. Update Google Maps Location
The map is currently pointing to Sharjah, UAE.

Search for: https://www.google.com/maps?q=Sharjah%2C%20UAE&output=embed

Replace with: Your specific map embed link from Google Maps.

6. Change QR Codes
QR codes are generated dynamically through an API. They currently link to your WhatsApp, Location, and Phone number. To change what they link to, update the data= parameter in the URL found in the QR code <img> tags.
